# Verbarium Weekly Streak · 7 dias

Sete fichas individuais: segunda, terça, quarta, quinta, sexta, sábado e domingo.

**Por dia:** `static/pending`, `static/completed`, `animated/webp` e `animated/gif`.

A animação dura aproximadamente 1,45 s e deve ser acionada somente quando o dia é marcado como concluído. O estado concluído deve permanecer depois do movimento. Para usuários que preferem movimento reduzido, mostre apenas a imagem estática. O valor da sequência e a contagem 0/7 devem ser renderizados como HTML, não dentro do PNG.

Transparência RGBA real nos PNGs/WebPs. Labels legíveis SEG, TER, QUA, QUI, SEX, SÁB, DOM.

O contador do desafio e as regras de streak precisam continuar dependentes de dados reais do aplicativo.
